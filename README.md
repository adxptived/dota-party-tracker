# Dota MMR Tracker Bot

Telegram-бот для пати игроков Dota 2: следит за ранкед-играми участников с момента
добавления и ведёт **общий лидерборд группы** — игры, оценка ±MMR, текущий MMR (≈),
медаль/ранг, винрейт и средний KDA. Данные берёт из **OpenDota** (API-ключ не нужен).

## ⚠️ Важно про MMR

Точного числа MMR в Dota 2 **нет ни в одном публичном API** — Valve закрыл выдачу ~2019.
Поэтому MMR **оценивается**:

```
текущий MMR ≈ стартовый MMR + (победы − поражения) × шаг     (шаг по умолчанию 25)
```

Стартовый MMR вводишь ты (при `/add` или через `/setmmr`), а бот считает игры и оценивает
изменение. Везде помечается значком «≈». Медаль/ранг, число игр, KDA и винрейт — **реальные**.

Ещё: OpenDota видит матчи игрока, только если у него в Dota 2 включено
**«Открыть публичные данные матчей»** (Настройки → Опции → Дополнительно). Если выключено —
бот покажет 0 игр.

## Запуск локально (Windows)

Токен уже прописан в `.env` (ключ `BOT_TOKEN`). Из папки проекта:

```bash
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m mmrbot
```

Бот работает по long-polling — держи окно/процесс открытым. Остановка — `Ctrl+C`.

> Если своего токена ещё нет: создай бота у **@BotFather**, скопируй `.env.example` в `.env`
> и вставь токен в `BOT_TOKEN`.

## Как пользоваться

1. Добавь бота в групповой чат пати (или пиши ему в личку).
2. Регистрируй аккаунты и играй:

```
/add https://www.dotabuff.com/players/123456789 Вася 5400
/add 123456789 Петя 4200
/stats            # полный лидерборд
/today            # что было за сутки
```

### Команды

| Команда | Что делает |
|---|---|
| `/add <ссылка или ID> [Имя] [MMR]` | добавить аккаунт (Dotabuff/OpenDota/Stratz-ссылка, SteamID64 или account_id) |
| `/list` | список отслеживаемых игроков |
| `/remove <Имя>` | убрать игрока |
| `/setmmr <Имя> <MMR>` | задать/поправить MMR (новая точка отсчёта) |
| `/setstep <шаг>` | шаг оценки MMR за игру (по умолчанию 25) |
| `/settime <час>` | час ежедневного дайджеста, МСК (по умолчанию 10) |
| `/stats` | полный лидерборд + серии (🔥/💧) + награды пати |
| `/today` | активность за последние сутки |
| `/together` | совместные игры пати: общий винрейт, лучшее дуо |
| `/heroes` | топ-3 героя каждого участника + винрейт по герою |
| `/player <Имя>` | карточка игрока: GPM/XPM/ластхиты, длительность, соло vs пати, винрейт по времени суток, герои |
| `/help` | справка |

### Метрики

- **Серии** — текущий винстрик/лузстрик (🔥/💧) в лидерборде.
- **Награды пати** (в `/stats`): 👑 Король винрейта, 🛠 Работяга (больше всех игр),
  🗡 Керри (лучший KDA), 💀 Фидер (больше всех смертей). Порог — от 3 игр.
- **Совместная игра** (`/together`) — сколько пати сыграла вместе и винрейт вместе,
  лучшее дуо. Считается по общим match_id участников (без лишних запросов).
- **Топ героев** (`/heroes`) — по числу игр + винрейт, имена из справочника OpenDota.
- **Глубокая стата** (`/player`) — средние GPM/XPM/ластхиты (из `/players/{id}/totals`),
  средняя/максимальная длительность, соло vs пати, лучший/худший час по винрейту.

## Запуск в Docker (для сервера)

```bash
docker compose up -d --build
docker compose logs -f
```

`.env` монтируется внутрь; база `mmrbot.db` сохраняется в volume.

## Как это устроено

- `mmrbot/ids.py` — разбор ссылок/ID в `account_id`.
- `mmrbot/ranks.py` — `rank_tier` → медаль.
- `mmrbot/stats.py` — чистые расчёты (win/loss, KDA, оценка MMR).
- `mmrbot/opendota.py` — клиент OpenDota (троттлинг + ретраи).
- `mmrbot/storage.py` — SQLite (чаты, игроки, кэш матчей).
- `mmrbot/tracker.py` — обновление игроков и сборка лидерборда.
- `mmrbot/formatting.py` — рендер сообщений.
- `mmrbot/bot.py` / `scheduler.py` / `__main__.py` — aiogram-хендлеры, дайджест, запуск.

Подробный дизайн — в [`docs/design.md`](docs/design.md).

## Заметки / ограничения

- За один запрос к OpenDota берём до 200 последних матчей. При ежедневном дайджесте этого
  с запасом хватает (матчи кэшируются инкрементально и не теряются между обновлениями).
- Дайджест шлётся раз в день в заданный час; если процесс был выключен в этот час дольше
  5 минут — дайджест за этот день пропустится (данные не теряются, доступны по `/stats`).
